# 📜 Правила работы с играми «Игротека ОГЭ»

Этот файл — **обязательная памятка** для любой будущей сессии Claude, который продолжит работу над играми. Перед тем как делать что-то новое, открой и перечитай.

## 🔒 Правило 1: Журнал использованных ID

- Файл `used_ids_journal.json` хранит список ID ОБЗ ФИПИ, которые уже использованы
- **Перед каждой новой игрой**: открой журнал, проверь, какие ID по нужному заданию уже использованы — НЕ бери их повторно
- **После создания новой игры**: обнови журнал — добавь новые использованные ID и пересохрани

## 🐝 Правило 2: Пчелиный бренд

Во всех играх и сайтах присутствуют пчёлки:
- 🐝 в названии счёта («Пчёлки: 5 / 8»)
- 🐝 в заголовках и подвалах
- 🍯 как награда за правильный ответ
- Цвета: жёлтый/медовый/коричневый
- В подвале сайта пишем: «🐝 Задания из ОБЗ ФИПИ · ЗебРус 2026» (русскими буквами)
- В модалке имени: «Чтобы педагог увидел твой результат...»

## 📚 Правило 3: ТОЛЬКО задания из сборника

- Все тексты, варианты ответов, правильные ответы берутся **дословно** из `/home/claude/intensive/sbornik.txt`
- **НИЧЕГО НЕ ВЫДУМЫВАТЬ.** Если задания не хватает — сказать пользователю, не приписывать своё
- После создания каждой игры — **сверить ответ с разделом «Ответы»** в сборнике
- Если в сборнике текст обрывается или испорчен парсингом — найти полный текст вручную, а не догадываться

## 🎨 Правило 4: Разметка ответов (визуальная обратная связь)

При проверке ответа в играх с множественным выбором — **4 состояния**:
- 🟢 Зелёный сплошной — ученик выбрал и это правильный ответ
- 🔴 Красный — ученик выбрал, но это неверный ответ
- 🟢 Зелёный пунктирный — правильный ответ, который ученик **не выбрал** (пропустил)
- ⚪ Серый — не выбран и не нужно было

**Снизу обязательно строка**: `🐝 Твой ответ: X · Правильный: Y`

CSS-классы: `.correct`, `.wrong`, `.missed` (пунктирный)

## 📝 Правило 5: Тексты целиком

- В заданиях с длинным текстом (5, 7, 10) — **показывать полный текст** над выбором ответа
- На «фишках» с выбором (цветах, кнопках, рыбках) — показывать слово/вариант **с пропуском** (например, «к..ртина», а не «кАртина»)
- Не маскировать буквы автоматически в JS — это глючит

## 🏆 Правило 6: Лидерборд

- В каждой игре: `let answersByTask = {}` хранит ответы во время игры
- При проверке: `logTaskAnswer(taskId, userAnswer, isCorrect, max)` — логирует ответ
- В конце игры: `submitGameResults(gameName, score, total)` — шлёт в Google Sheets
- Название игры должно совпадать с названием вкладки в `Таблица_шаблон.xlsx`

## 🔄 Правило 7: Имя ученика и модалка

- При первом заходе на сайт: спросить имя через модалку
- Сохранить в `localStorage.crashIntensiveUserName`
- В верхнем правом углу — кнопка с именем для смены
- Перед началом любой игры: проверить, есть ли имя, если нет — показать модалку

## 📋 Правило 9: Проверка после сборки

Перед тем как отдать пользователю файл:
1. Подсчитать `{` и `}` — должны совпадать
2. Подсчитать `<script>` и `</script>` — по одному
3. Проверить, что нет ссылок на ID, которые не определены
4. Скопировать в `/mnt/user-data/outputs/`

## 🚫 Правило 10: Чего НЕ делать

- НЕ выдумывать варианты ответов
- НЕ использовать в новой игре ID, которые уже есть в журнале
- НЕ упоминать «Олечка Александровна», «ZebRus» (англ.), «кукушечка», «Ушки на макушке», «первая мысль от Бога»
- НЕ показывать готовые буквы на фишках — только пропуски
- НЕ подсвечивать все правильные ответы зелёным независимо от выбора ученика
- НЕ удалять старые игры или сайты без явной просьбы
