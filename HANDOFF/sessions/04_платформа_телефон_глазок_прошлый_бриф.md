# Сессия «Create exam prep platform for students»

**Тема:** баг с глазком сочинений на телефоне + подготовка переноса проекта в новую вкладку.

---

## Баг с глазком

[user] где сочинение ученика есть глазок, открыв его на компьютере я вижу как видит ученик мои пометки, с телефона глазок не активен

[assistant] Поняла — кнопка-глазок не реагирует на тап на телефоне. Причина: 32×32 px — слишком маленькая мишень для пальца (Apple рекомендует минимум 44×44), плюс родительская строка перехватывает тап.

Также: глазок открывает модал «как у ученика» — он берёт данные из реальных DB-сочинений (с проверкой, баллами, замечаниями). У тестовых учеников вроде «Анна Соколова», «Настя Колобаева» этого нет — модал возвращается пустым, выглядит как «ничего не происходит».

**Рекомендация:** спрятать глазок у моков, либо проверять на реальном ученике с заполненным сочинением.

Содержание брифа:
1. Кто пользователь и контекст
2. Что за проект (ЗебРус, Краш-тест 2026)
3. Архитектура (Supabase + PHP-прокси + GitHub Pages)
4. Особенности (РФ-блокировки, кастомный JWT, баги прокси)
5. Список всех файлов с расположением

8. Правила работы (пуш руками, миграции вручную, без программерского жаргона)
9. Технические данные (URL, ключи, repo)

**Инструкция по переносу:**
1. В новой вкладке Claude создать Project.
2. В Project knowledge загрузить:
   - `CLAUDE_BRIEF.md` (обязательно — теперь это `HANDOFF/HANDOFF.md`)
   - `чат-история.md` (опционально, глубокий контекст)
   - `schema.sql` (структура БД для справки)
3. В первом сообщении новому Claude: «Привет. Я Ольга, продолжаю проект ЗебРус. В Project knowledge — бриф, прочитай его и продолжим работу.»

Файлы кода (`index.html`, `sql/`, и т.д.) в той же папке `~/Documents/Claude/Projects/Приложение/`, новый Claude через Read/Write/Edit будет с ними работать как обычно.
