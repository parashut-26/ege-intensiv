**Контекст 2026-05-13:** У Ольги в Notion работает AI-помощник, который по промту пишет анализ работ ученика и даёт советы. Хочет аналогичное в ZebRus — отдельную колонку «Рекомендации» в сводной варианта.

**Архитектура:**
1. Supabase Edge Function `ai-recommend` — прокси к нейросети чтобы API-ключ не светился на клиенте
2. Принимает `attempt_id` или `student_id + variant_id`
3. Загружает ответы ученика, формулировки вопросов и правильные ответы
4. Собирает промт «Ученик решил вариант. По заданиям 5, 8, 22 допустил ошибки в …. Дай 2-3 конкретные рекомендации что подтянуть»
5. Возвращает текст рекомендации, кэширует в БД

**Выбор провайдера:**
- **YandexGPT** — РФ-резиденция, гарантированный доступ без VPN. ~₽0.20-0.40 за запрос. https://cloud.yandex.ru/services/yandexgpt
- **GigaChat (Сбер)** — тоже РФ. Стоимость аналогичная
- **OpenAI / Anthropic** — лучшее качество, но платить только через зарубежные карты + есть риск блокировки от РФ-юзеров

Рекомендую начать с YandexGPT — проще всех.

**SQL:**
```sql
CREATE TABLE ai_recommendations (
  id SERIAL PRIMARY KEY,
  attempt_id INT REFERENCES test_variant_attempts(id) ON DELETE CASCADE,
  recommendation_text TEXT,
  provider TEXT,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  UNIQUE(attempt_id)
);
```

**UI:**
- В сводной варианта добавить колонку «🤖 Рекомендация» — текст или кнопка «Сгенерировать»
- Кнопка → вызывает Edge Function → сохраняет в БД → показывает в ячейке
- В детальном виде ученика тоже показать рекомендацию

**Why:** Ольга не успевает дать персональные рекомендации каждому ученику. AI делает это за неё, она проверяет/правит. Аналогично её Notion-сетапу.

**How to apply:** После интенсива 2026 (после 4 июня). Раньше — рискованно: требует API-ключи, инфраструктуру, тестирование на качество промта. До тех пор можно вручную копировать ответы ученика и спрашивать ChatGPT/Claude.

**Идея промта (для первой версии):**
```
Ты эксперт-репетитор по русскому языку ЕГЭ. Ученик {имя} только что решил пробник «{вариант}», набрав {N}/{макс} баллов.
Ошибки по заданиям:
{список — для каждой неверной задачи: №, тема, его ответ, правильный ответ}

Дай 2-3 конкретные рекомендации что подтянуть. Используй "ты", дружелюбный тон. Без воды. Не больше 80 слов.
```
