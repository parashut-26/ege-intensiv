В проекте Supabase (hyczawwuehrqsqqosgub) на странице Settings → JWT Keys → Legacy JWT Secret поле «Access token expiry time» установлено в **604799 секунд** (~7 дней без 1 сек), 2026-05-06.

**Why:** Дефолтный 1 час слишком мало для 3-дневного интенсива (30 мая — 4 июня). Refresh token из браузера не пробивается, потому что `/auth/v1/token` блокируется в РФ — поэтому растягиваем сам access token вместо того, чтобы полагаться на refresh. Бесплатный тариф режет cap до «менее 604800» секунд.

**How to apply:** Если в будущем перейдём на Pro — можно поднять до 30 дней (2592000) для запаса. Если ученики жалуются на разлогин в середине интенсива, проверять, что cap не сбросили обратно на 3600. Если понадобится дольше 7 дней без апгрейда тарифа — нужен прокси (Cloudflare Worker → /auth/v1/token), чтобы автоматически обновлять токены в обход блокировки.
