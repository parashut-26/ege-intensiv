**Продукт:** «Краш-тест 2026» — 3-дневный интенсив перед ЕГЭ по русскому.
Ближайшая итерация: 30 мая (пт) — 2 июня (пн) — 3 июня (вт), экзамен 4 июня.
- День 1 — Орфография + задания 4–6
- День 2 — Пунктуация + задания 7–8
- День 3 — Текст + задание 21
Структура каждого дня: УТРО (разминка-тренажёр) → 13:00 ВЕБИНАР (2–2,5 ч) → 18:00 РАЗБОР.

**Существующий лендинг (тёмная тема):** https://parashut-26.github.io/krash-test-2026/
Палитра лендинга: тёмно-фиолетовый/чёрный фон, ярко-жёлтый акцент (#FACC15-подобный), фиолетовые градиенты, оранжево-персиковые карточки.

**Платформа (светлая тема, мокап у Ольги уже есть):**
- Шапка: лого ZebRus + жёлтый пилл «🐝 Краш-тест 2026», справа счётчик пчёлок и аватар.
- Вкладки ученика по мокапу: Главная / Дни интенсива / База знаний / Достижения / Профиль. (Чата в мокапе нет — уточнить, нужен ли.)
- Геймификация: «пчёлки» (баллы), серии активных дней, прогресс-бар «Твой путь к ЕГЭ».
- **Принцип достижений (важно для Ольги):** интенсив идёт ПЕРЕД ЕГЭ — нельзя добавлять стресс. Все ачивки должны быть **доступны каждому**, кто заходит и работает. Никаких «лучших из лучших», «топ-10», «королев улья». Категории:
  (1) «За то, что ты тут» — приход, разминка, посещение, сдача сочинения по факту;
  (2) «Соревнуешься с собой» — рост между попытками, точность на одном тесте, работа над ошибками;
  (3) «Социальное» — учитель в чате может пометить ответ ученика как «помогло», ученик получает «🤝 Помогла другу». Это ключевая идея Ольги.
  (4) Финальная «👑 Прошла Краш-тест» открывается у всех, кто дошёл до экзамена.
- Карточка активного дня — оранжево-персиковый градиент, кнопки «Начать разминку», «Расписание дня».
- KPI-плашки: пчёлки, заданий пройдено, средний балл, серия дней.
- Карта интенсива — 6 карточек (3 дня + 2 «прогулки с друзьями»-мотивация + день экзамена).
- Лента активности: «9/10 разминка +5🐝», «вебинар посещён +3🐝» и т.п.
- Тон: дружелюбное «ты», обильно пчелиная тематика, эмодзи допустимы.

**Учитель — Ольга Александровна** (на платформе, не «Ольга Викторовна», как было в моём первом прототипе).

**Кураторы** (третья роль на платформе): София и Анастасия (выпускницы Ольги или сильные ученицы — уточнить). Помогают вести интенсив. Права:
- Могут: видеть прогресс всех учеников, писать в чате (общий + личные), ставить «🤝 помогло» на ответы учеников (для бейджа «Помогла другу»), делать **предварительную проверку сочинений** (выставлять К1–К10 + комментарии — попадает к учителю на финальное утверждение), читать Базу знаний и Образцы.
- Не могут (по умолчанию): создавать/удалять задания и материалы, управлять расписанием, одобрять гостей. Эти права **гибкие** — учитель в карточке куратора через переключатели «Расширенные права» может их **выдать индивидуально** (например, только Софии разрешить загрузку материалов). Меняется в любой момент.
- Не могут (всегда, без переключателей): финализировать оценки сочинений, удалять учеников, менять настройки группы, создавать новые интенсивы. Это эксклюзивно учительская зона.
- В чате — значок «куратор» под сообщением. В списке учеников — отдельный значок роли.
- Если куратор одновременно учится — переключатель в аккаунте между «я ученик» / «я куратор», чтобы прогресс не путался.

**Кабинет учителя по мокапу:**
- Шапка: фиолетовый пилл «🐝 Кабинет учителя» (vs жёлтый «Краш-тест 2026» у ученика), колокольчик уведомлений, плашка имени.
- Вкладки: Сводка / Ученики / Сочинения / Аналитика / Дни интенсива (+ Прочее → Настройки).
- Сводка: KPI (учеников, активны сегодня, средний балл, не приступали), оранжевая плашка с заявками на одобрение, «Слабые места группы» (бары % ошибок по темам), очередь сочинений.
- Ученики: типы «Свой» (постоянный ZebRus) и «Гость» (оплатил конкретный интенсив, требует одобрения учителя). Статусы: активна / отстаёт / ждёт одобрения. В списке: прогресс-бар, пчёлки, средний балл, кнопки «👁 посмотреть» и «💬 написать».
- Сочинения проверяются руками (задание 27 не автоматизируем). Сетка — **К1–К10**, **итог 22 балла** (не 21). Файл с официальными критериями загружен Ольгой 2026-05-04 — это источник истины. Структура баллов: К1=1, К2=3, К3=2, К4=1, К5=2, К6=1, К7-К10 по 3.
- **Жёсткое правило К1→К2,К3:** если К1=0, то К2 и К3 автоматически = 0 (по тексту методички). В форме это блокировка с пояснением.
- **Минимум 150 слов.** В редакторе ученика — счётчик слов с подсветкой; <150 = вся работа 0 по всем критериям. Правила подсчёта: «всё-таки» = 1 слово, «всё же» = 2, цифры и знаки не считаются, инициалы с фамилией = 1 слово.
- В форме проверки К7–К10 ввод по числу ошибок (0→3, 1-2→2, 3-4→1, 5+→0), не по баллам.
- Ученики сдают сочинение либо текстом во встроенном редакторе (комментарии к выделенным фрагментам), либо фото рукописи (нумерованные комментарии). Учитель — split-страница: слева работа, справа критерии. **Голосовые комментарии** в окошке комментария: MediaRecorder → Supabase Storage. Минута ≈ 240 КБ.
- **Голосовые комментарии** в проверке сочинений: учитель в окошке комментария может нажать «🎤 Записать голос» (MediaRecorder → Supabase Storage), ученик видит ▶ плеер рядом с подсвеченным фрагментом. Минута ≈ 240 КБ — экономно. На iOS Safari может требовать повторный тап.
- Онбординг: «свои» создаются учителем (имя+e-mail, magic link на почту, статус сразу `активна`). «Гости» саморегистрируются → попадают в статус `ждёт одобрения` → учитель одобряет/отклоняет в Сводке.
- **Чат — встроенный, в платформе.** (Не Telegram.) Будут общий чат группы и личные диалоги ученик↔учитель.
- «Прогулки с друзьями» (31 мая, 1 июня) — лёгкий контент между рабочими днями (видео, мини-викторины, мотивация). Тип карточки в карте интенсива.

**Пояснения к достижениям обязательны и видны постоянно** (важная правка Ольги): не во всплывашке, а на самой карточке бейджа во вкладке «Достижения», в ленте активности возле «+🐝», в toast при открытии бейджа, в коротком онбординге при первом входе и в разделе «Что я могу получить» в профиле.

**Раздел «Теория» в платформе:** сетка 26 карточек (по числу тестовых заданий) с темой каждого номера. Клик по номеру → детальная карточка с теорией, материалами и тестом по этому заданию. Привязка идёт через `task_number` в БД.

**Сборка случайного варианта:** в тренажёрах есть кнопка «Собрать вариант ЕГЭ» — система берёт по 1 случайному вопросу из банка для каждого номера 1–26, выдаёт таймированный полный вариант. Это требует, чтобы в банке было хотя бы 5–10 вопросов на каждый номер; пока банк пуст, нужно собирать его постепенно.

**OCR рукописных сочинений** (план): когда ученик присылает фото листов с рукописью, система автоматически распознаёт текст (Claude/GPT-4V / Yandex Vision / ABBYY). Учитель видит и фото, и распознанный текст параллельно — может комментировать любую сторону. Особенно ценно для тренировки рукой и при этом удобной обратной связи.

**Раздел «Образцы» в Базе знаний** (план): несколько проверенных экспертами сочинений на разный балл (22, 18, 14, 8) с разбалловкой по К1–К10 и комментариями. Используется как учебный материал и мотиватор для учеников. Ольга прислала первое такое сочинение (на 22 балла, тема Ваншенкина «опыт службы в армии») 2026-05-04.

**ИИ-ассистент в проверке сочинений (план на будущее, не на ближайший интенсив):** ИИ как помощник, не замена. Сильные стороны — первичная разметка орфо/пункт/грамм/речевых ошибок, автоподсчёт К7–К10 (после одобрения учителем), проверка формальностей (≥150 слов, наличие двух примеров, смысловой связи, К1). Слабые — К3, К5, соответствие проблеме (нужен живой педагог). План: фаза 1 — ручная проверка (сейчас), фаза 2 — «🤖 первичная разметка» в кабинете учителя, фаза 3 — «Проверь меня» для ученика до сдачи. Стоимость ~5 центов/сочинение, для приватности — Yandex GPT / GigaChat (РФ-резиденция).

**Посещаемость** (важное требование Ольги — времени отмечать на уроке нет):
- Гибрид: ученик во время вебинара видит на главной плашку «Я на уроке» — самоотметка серой галочкой.
- Учитель в кабинете открывает простой список (один экран на телефоне), быстро тапает галочки. На группу 20 чел. — ~30 сек.
- Авто-детект: активность в чате в момент вебинара / открытие разбора = «был».
- Сводка дня: «19/26 на вебинаре». Лента активности у ученика: «Посещён вебинар День 1, +3🐝».

**Оплаты** (Ольга сейчас ведёт в Битрикс24, хочет в одном месте):
- Отдельная вкладка «💰 Оплаты» в кабинете учителя. По каждому ученику — статус (оплачено/частично/ждёт/возврат), сумма, дата, способ, заметка.
- Сводка сверху: «Собрано X из Y ₽ · N ждут».
- При одобрении гостя — поле «Сумма оплаты» сразу в плашке заявки.

**Родительский кабинет** (план на будущее, не на ближайший интенсив):
- Четвёртая роль. Привязка через кабинет учителя: открыть карточку ученика → блок «Родители» → e-mail родителя → приглашение.
- 1 родитель может видеть нескольких своих детей; 1 ребёнок — обоих родителей.
- Видит: прогресс, посещаемость, пчёлки/достижения, статус сочинений (без полного текста). Получает еженедельный e-mail-отчёт.
- НЕ видит: материалы, теорию, тексты тестов (чтобы не утекало к репетиторам-конкурентам), других учеников, чаты, полные сочинения.
- Архитектура закладывается сейчас, UI добавляется позже.

**Учёт попыток в тренажёре** (важная UX-правка Ольги): кнопки «Сбросить» нет. Ученик отвечает → «Проверить» → видит ошибки и подсказки → «Сохранить и закрыть» или «↻ Пройти ещё раз» (новая попытка, старая в истории). В БД таблица `attempts`: student_id × task_n × score × timestamp × answers JSON. Виды отображения:
- ученику в профиле: «История моих попыток» по каждому заданию
- учителю в карточке ученика: те же попытки + агрегаты
- в аналитике группы: средний балл = по последней попытке; «среднее число попыток до 100%» = индикатор сложности
