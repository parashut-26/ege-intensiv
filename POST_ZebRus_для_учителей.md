# Пост для канала / чата учителей

Версия для Telegram-канала. Скопировать в Telegram → текст ляжет с теми же эмодзи и разделами.

🐝 **Коллеги, делюсь тем, что у нас получилось**

Готовясь к экзаменам, я столкнулась с тем, что моя работа размазана по семи окнам: Online Test Pad для пробников, Notion для аналитики, Битрикс для оплат, Excel для К1–К10, Google Drive для материалов, Telegram для общения, почта для всего остального. На одного ученика — пять переключений в минуту.

Год я собирала **ZebRus** — собственную платформу для подготовки к ЕГЭ по русскому. Сейчас на ней живёт мой текущий «Краш-тест 2026» (3-дневный интенсив перед экзаменом), и платформа дошла до состояния, в котором ею **уже можно пользоваться**. Рассказываю, что в ней есть — может быть, кому-то будет полезно.

---

📚 **Что видит ученик**

— Личный кабинет с картой интенсива: дни, расписание, утренние разминки, вебинары, разборы.

— **Тренажёры по всем 26 заданиям ЕГЭ** в реальных форматах: вставить букву в слово, кликнуть запятые в нужных местах, сопоставить, выбрать варианты, ввести ответ цифрами. Не куцый «выбери из 4 вариантов», а как на самом экзамене.

— **«Чемодан без ручки»** — личный банк ошибок ученика. Все слова и вопросы, на которых он спотыкался, копятся в одном месте. Когда ответил верно 3 разных дня подряд — задание «закрывается». Своего рода персональная зона роста.

— История попыток с разбором ошибок и пояснениями.

— **Сочинения**: ученик может сдать либо текстом в редакторе, либо фото рукописи. Учитель ставит комментарии прямо к фрагментам, может **записать голосовое** объяснение в окошке комментария. Дёшево, быстро, ученик слышит интонацию.

— **Пчёлки** (внутренние баллы) и достижения. Тут принципиально: никаких рейтингов, никаких «топ-10», никаких «королев улья». Перед экзаменом стресс не добавляем — все ачивки доступны каждому, кто работает. Категории: «За то, что ты тут», «Соревнуешься с собой» (рост между попытками), «Социальное» (когда учитель помечает твой ответ «помогло» — ты получаешь бейдж «🤝 Помогла другу»). Финальное «👑 Прошла Краш-тест» открывается у всех, кто дошёл до экзамена.

— Чат с учителем и общий чат группы — внутри платформы, не Telegram. Можно слать файлы, голосовые, редактировать свои сообщения.

— **Push-уведомления** — работают и на iPhone (через PWA), и в Chrome. Когда учитель выложил новый материал или проверил сочинение — приходит уведомление.

---

👩‍🏫 **Что видит учитель**

— **Сводка по интенсиву**: KPI (учеников, активны сегодня, средний балл, не приступали), оранжевая плашка с заявками на одобрение, **слабые места группы** баром процентов ошибок по темам, очередь сочинений, новые поступления оплат.

— **Список учеников** с фильтрами: «свои» постоянные / «гости» на интенсив, активны / отстают / ждут одобрения. У каждого — прогресс-бар, пчёлки, средний балл, кнопки «👁 посмотреть» и «💬 написать».

— **Карточка ученика** с подробной картиной: история попыток сгруппирована по 26 заданиям, слабые темы (где средний балл < 70%), «чемодан без ручки», заметка учителя (приватная — ученик не видит), история оплат.

— **Проверка сочинений по К1–К10** (итог 22 балла, не 21 — это важно). Жёсткое правило К1=0 → К2,К3 автоматически 0 запрограммировано. Счётчик слов с подсветкой ≥150. Сплит-страница: слева работа, справа критерии. Голосовые комментарии к фрагментам.

— **Банк теории и тестов**. Все 26 номеров с теорией и вопросами. **Можно править вопросы прямо в кабинете** — добавлять свои, исправлять формулировки, дописывать пояснения.

— **Аналитика по группе**: средний балл, тепловая карта по заданиям, слабые темы, экспорт в CSV.

— **Дни интенсива** с программой, материалами, прогулками-мотиваторами между рабочими днями.

— **Посещаемость**: гибрид — ученик ставит галочку «я на уроке», учитель быстро тапает по списку на телефоне (~30 сек на группу 20 человек), автодетект по активности.

— **Оплаты**: отдельная вкладка с группировкой по месяцам, фильтрами, ручным добавлением, CSV-экспортом. Платежи можно фиксировать через **Telegram-бот**: ты пересылаешь уведомление от Т-банка в нашего бота, он распознаёт сумму/ФИО/email/номер операции, ищет ученика по этим полям и предлагает «привязать одним кликом». Дедуплицирует автоматически.

— Импорт результатов с Online Test Pad, импорт списка учеников из таблицы, приглашения через одноразовые коды или magic link.

---

🤝 **Третья роль — куратор**

Это для выпускниц или сильных учениц, которые помогают вести интенсив. Куратор видит прогресс всех учеников, общается в чате, ставит «помогло» на ответы (этот ответ потом превращается в бейдж для ученика), может **предварительно проверить сочинение** — учитель потом финализирует. Расширенные права (загружать материалы, утверждать заявки) учитель выдаёт индивидуально, через переключатели в карточке куратора. Если куратор сама ещё учится — в её аккаунте есть тумблер «я ученик / я куратор», чтобы прогресс не путался.
